Forge is Cox Automotive's internal artifact hosting platform. It turns the HTML pages, dashboards, and React tools you build in Claude into real, shareable URLs anyone inside Cox can open — no IT ticket, no dev deployment, no SharePoint link rot.

What it is

Your own deployment pipeline,
minus the engineering team

Think of Forge like a private GitHub Pages, purpose-built for Cox. You build an HTML page or React component inside Claude, tell Forge to publish it, and get back a live URL that anyone inside Cox can open right now.

Artifact hosting

HTML pages and React components built in Claude become real web pages with permanent URLs. No copy-pasting into SharePoint or emailing HTML files.

Two-click publish

Say "publish this to Forge" in Claude. Confirm the title and visibility. That's it. The connector handles the upload behind the scenes — no code, no terminal.

Version history

Update an existing artifact and Forge keeps the same URL but serves the new version. Load an old artifact back into Claude, edit it, republish — round-trip editing built in.

Internal-only access

Artifacts can be set to Private (just you) or Internal (all Cox employees). Nothing is publicly accessible. No accidental exposure of dealer data or internal tooling.

React support

React and TSX components are bundled server-side. React 18 and Tailwind CSS are pre-wired — declare only external dependencies like Recharts or Lodash in your publish call.

Claude-native round trips

Load an existing artifact back into the conversation with one command. Edit it with Claude, then republish. The URL stays the same. No file management, no versioning headaches.

How to get it

Two things you need

Access to Forge requires the Forge platform itself (your web destination) and the forge-dxt connector (the bridge between Claude and the platform). Both are Cox internal.

1 — The Forge platform

Forge lives at the Cox Automotive internal artifact hub. You access it through your standard Cox SSO credentials. No separate account creation needed.

Your artifacts and your team's published tools are all discoverable from the Forge dashboard once you're in.

Open Forge dashboard

2 — The forge-dxt connector

The connector is a browser extension (or Claude.ai MCP connector) that allows Claude to communicate with Forge directly. Version 3.1.0 or later is required.

Install it from the Cox internal extension catalog. Once installed, it will appear as an enabled connector in your Claude.ai settings under Connected Apps.

Find it in the internal catalog

Who can access it

Forge is available to all Cox Automotive employees. Artifacts published with Internal visibility are accessible to any authenticated Cox employee — no additional access requests required for viewers.

Need help getting in

If the connector is missing from your catalog or you get an auth error on Forge, reach out via the internal AI Council Slack channel. The team can troubleshoot access and connector version issues.

Install the connector

Getting forge-dxt connected

The connector is the bridge. Without it, Claude knows about Forge but can't actually push anything there. Here's how to wire it up.

1

Open Claude.ai settings

In the Claude.ai web interface, click your profile icon in the bottom-left corner, then choose Settings. Look for the Integrations or Connected Apps section.

2

Find the forge-dxt connector

Search for forge-dxt or browse the Cox Automotive-specific connectors. If it isn't listed, access the Cox internal extension catalog and install from there first — it will then appear in Claude's connector list.

Version requirement: The connector must be version 3.1.0 or later. If you have an older version installed, the Forge skill will surface an upgrade prompt before it does anything else.
3

Enable it for your conversations

Toggle the connector on. In some conversations you may need to activate it per-session from the tools panel. Once enabled, Claude gains access to the Forge publish, list, search, and load tools.

4

Authenticate with Forge

The first time you publish, Forge may ask you to link your session with a short authorization code in the format XXX-XXX-XX. You'll see this code on the Forge web page — paste it into Claude when prompted. Your session stays linked for future publishes.

One-time setup: Once your session is linked, subsequent publishes skip this step. The connector rotates your credentials automatically after each successful publish.
5

Verify it's working

Ask Claude: "What Forge artifacts do I have?" Claude will call list_artifacts and return your published items. If you see results (or an empty list with no error), you're connected and ready to publish.

How to use it

Three things Forge can do for you

Forge operates through natural language in Claude — you don't call tools directly. Just say what you want to do and Claude handles the rest.

Publish a new artifact

Most common

After building something in Claude, just ask it to publish. Claude will scan the conversation for artifact content, propose a title and description, ask you to confirm visibility, then push it to Forge.

  • Say "Publish this to Forge" (or "Share this artifact")
  • Pick Update existing or Publish as new
  • Confirm title, description, and visibility (Private or Internal)
  • Copy the live URL Claude returns

Edit an existing artifact

Paste a Forge URL into Claude and ask it to edit the artifact. Claude loads the current version back into the conversation so you can make changes, then publishes the updated version to the same URL.

  • Say "Edit my Forge artifact at [url] and change..."
  • Claude loads the current HTML into the conversation
  • Describe your changes and Claude applies them
  • Publish — same URL, new version

Find your artifacts

Ask Claude to list or search your published artifacts. Claude uses the Forge search and list tools to find what you've published, show metadata, and let you pick one to edit or share.

  • Say "What Forge artifacts do I have?"
  • Or "Find my Forge artifact about the Fullpath briefing"
  • Claude returns titles, dates, and URLs
  • Pick one to open, edit, or reshare

Visibility and sharing

Every artifact has one of two visibility levels. Pick the right one before publishing — it can be changed by republishing with updated metadata.

  • Private Only you can view it. Use for drafts or personal tools.
  • Internal Any Cox employee with the URL can open it. Use for team sharing.
  • Note Nothing on Forge is ever publicly accessible outside Cox.
